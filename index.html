Quickstart Guide

You should see this directory containing:

index.html, error/, webserver.py

Put your index in index.html, as usual.

Put your HTTP errors in error/ (403 & 404 only supported so far)

Run webserver.py to launch the webserver. PLEASE NOTE: IT CAN BE EASILY ACCESSED! SIMPLY BY localhost:8080/webserver.py

How to start up HTTP error managment

There are some easy steps to follow:

  1. Enter your directory
  2. Create / Ensure there is a folder named 'error'.
  3. Create HTML files for your HTTP error. E.g: 404 error would be 404.html
  4. Open webserver.py (or whatever you named your webserver controller to be)
  5. Set the "Use HTTP errors in error/httpname.html" setting to be True.
  6. Test it out by entering a false webpage.

Features

  1. Allows using [website]/ and [website] rather than fully entering [website]/index.html
